# Submission checklist — Personal Portfolio Website

- [ ] Copy `.env.example` to `.env` and configure MongoDB URI + JWT secret.
- [ ] `npm install` completes successfully.
- [ ] Server starts and `/api/health` returns `{"ok":true}`.
- [ ] Register a normal user and test login/logout.
- [ ] Test all project-specific create/read/update/delete or order/comment flows.
- [ ] Test on mobile width and desktop width.
- [ ] Add your own real content, screenshots, profile details and contact links.
- [ ] Deploy backend with environment variables and a managed MongoDB database.
- [ ] Test deployed URL from a private/incognito browser.
- [ ] Submit source repository URL + live URL + screenshots.

Do not submit until you have run the application and verified the checklist. The project source is a working foundation, not proof that deployment or external grading has passed.
